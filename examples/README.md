# 示例

每个 `.json` 是可直接喂给 `scripts/pipeline.py` 的 spec。

```bash
python scripts/pipeline.py --spec examples/beijing_3days.json --out plan.json
```

| 文件 | 城市 | 天数 | 候选点 | 实测结果 |
|---|---|---|---|---|
| `beijing_3days.json` | 北京 | 3 | 14 | 利用率 88%，交通 4.0h，必去点全覆盖 |
| `chengdu_2days.json` | 成都 | 2 | 9 | 利用率 87%，9 点全部定位成功 |

## spec 字段

`assets/spec_template.json` 是带注释的完整模板。除 `city` / `days` / `places` 外都可省略。

### 顶层

| 字段 | 默认 | 说明 |
|---|---|---|
| `city` | 必填 | 城市名，用于确定搜索范围 |
| `days` | 3 | 天数 |
| `pace` | `"标准"` | `轻松`(×0.75) / `标准` / `紧凑`(×1.25) |
| `travel_mode` | `"hybrid"` | `hybrid`(步行+打车) / `pedestrian` / `auto` / `bicycle` |
| `day_start` | 540 | 每日出发时刻（分钟数，9:00 = 540） |
| `day_end` | 1260 | 每日最晚结束时刻 |
| `max_pois_per_day` | 6 | 每天最多几个点 |
| `bbox_span` | 0.32 | 地理编码搜索范围（度） |

### 权重（可选，一般不用动）

| 字段 | 默认 | 调大后 |
|---|---|---|
| `w_travel` | 1.0 | 更重视少走路 |
| `w_value` | 60 | 更不愿塞低分景点 |
| `w_ticket` | 2.0 | 更倾向免费景点 |
| `w_balance` | 150 | 每天收工时间更接近 |
| `long_leg_min` | 45 | 允许更长的单段移动 |
| `stretch_factor` | 0.6 | 更激进地避免跨区 |
| `insert_threshold` | 900 | 更愿意塞点（可能很赶） |

### places

| 字段 | 默认 | 说明 |
|---|---|---|
| `name` | 必填 | 地名。**用规范全名**（"中国国家博物馆"而不是"国家博物馆"） |
| `lat` / `lng` | 自动 | 留空则用 Photon 地理编码（WGS-84）。给了就跳过编码 |
| `visit_min` | 90 | 游览时长（分钟） |
| `priority` | 3 | 1=必去 2=重要 3=可选 4=备选 |
| `rating` | 4.0 | 0–5 分 |
| `ticket` | 0 | 门票（元） |
| `open_time` | 540 | 开放时刻（分钟数） |
| `close_time` | 1080 | 闭馆时刻 |
| `closed_days` | `[]` | 闭馆日，0=周一、6=周日 |
| `category` | `""` | 分类，仅用于展示 |
| `indoor` | `false` | 是否室内（雨天友好，目前仅标记） |

### 游览时长参考

填不准会明显影响结果。经验值：

| 类型 | 分钟 |
|---|---|
| 大型博物馆 / 宫殿（故宫、陕历博） | 150–180 |
| 中型博物馆、寺庙 | 60–90 |
| 公园园林 | 90–150 |
| 历史街区（南锣鼓巷、宽窄巷子） | 60–90 |
| 地标拍照（鸟巢、天安门广场） | 30–45 |
| 山岳景区（长城、峨眉山） | 180–300 |

## 闭馆日常识

国内多数博物馆、纪念馆 **周一闭馆**（`closed_days: [0]`）。故宫也周一闭馆（法定节假日除外）。排行程前建议按实际情况填写，否则会排出"周一去故宫"这种行程。

## 注意

这两个示例的 POI 元数据（开放时间、门票、时长）是写死的静态值，**仅用于演示求解器**。实际出行前请以官方信息为准。
